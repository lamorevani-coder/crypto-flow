# crypto-flow\n\nProduction-oriented multi-exchange cryptocurrency market-data & order-flow connector.\n\nCollects real-time trades from Binance, Bybit, OKX, Coinbase, Kraken, Bitfinex, Hyperliquid, Deribit (and extensible), normalizes to unified schema, computes delta / CVD / global spot-vs-perp flow, stores in TimescaleDB, and exposes REST + WebSocket API.\n\n## Priority metrics (v0.1)\n\n- Per-exchange BTC Spot Delta / Perp Delta\n- GLOBAL BTC SPOT DELTA\n- GLOBAL BTC PERP DELTA\n- Spot vs Perp divergence\n- Exchange contribution breakdown\n- Data quality / coverage\n\n## Architecture\n\n```\nExchange WS/REST → Adapter → Normalizer → EventBus → FlowEngine → Storage (TimescaleDB)\n                                                              ↓\n                                                         Unified API (REST + WS)\n```\n\n## Stack\n\n- Python 3.12+\n- FastAPI + asyncio + websockets + httpx\n- Pydantic v2\n- SQLAlchemy 2 async + asyncpg + TimescaleDB\n- Docker Compose\n\n## Quick start\n\n```bash\ncp .env.example .env\n# edit passwords if needed\ndocker compose up -d --build\n```\n\nAPI will be on http://localhost:8000\n\n- GET /health\n- GET /health/detailed\n- GET /exchanges\n- GET /flow/delta?symbol=BTC&market=spot\n- GET /flow/global/BTC\n- GET /flow/BTC/spot-vs-perp\n- WS /ws\n\n## Supported exchanges (v0.1 focus)\n\n| Exchange     | Spot | Perp | Aggressor | Status   |\n|--------------|------|------|-----------|----------|\n| Binance      | ✓    | ✓    | native (m)| primary  |\n| Bybit        | ✓    | ✓    | native (S)| primary  |\n| OKX          | ✓    | ✓    | native    | primary  |\n| Coinbase     | ✓    | -
